## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (`SolonKarandanis/event-ticketing-platform`), managed via the `gh` CLI. External PRs are not a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Default label vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`) used as-is. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context layout — `CONTEXT-MAP.md` at the root points to a per-service `CONTEXT.md` (`ticket-service/`, `analytics-service/`, and eventually `frontend/`). See `docs/agents/domain.md`.
